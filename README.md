# jmclarenscripts
A repo for my app portfolio website.

## Structure

This repository contains the following:

- `index.html` - Main HTML file for the portfolio website
- `css/` - Stylesheets directory
  - `style.css` - Main stylesheet with responsive design
- `js/` - JavaScript directory
  - `main.js` - Main JavaScript file
- `images/` - Directory for image assets
- `.gitignore` - Git ignore file for web development

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser to view the website
3. Modify the HTML, CSS, and JavaScript files to customize your portfolio

## Deployment

This website can be deployed to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service
